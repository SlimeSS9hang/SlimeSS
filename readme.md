## 🇬🇧 English

**SlimeSS** is a screenshot & screen recording app for Windows: lightweight, fast, handy hotkeys.

### ✨ Features

- 📸 **Capture:** fullscreen, active window, custom region, all running windows (grid collage)
- 🎥 **Record:** fullscreen, window, custom region, fixed app
- 🖥️ **Multi-monitor:** auto-follows the monitor with your cursor, keeps aspect ratio
- 🎞️ **Record directly to GIF**
- ⌨️ **Customizable hotkeys**, export/import JSON configs
- 🗂️ Files auto-organized into month/year folders
- 👁 **Instant preview** after capture/record
- 🌐 Bilingual: English & Vietnamese
